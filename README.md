# Redesign Hero Section Grafologi Indonesia

## Overview
Halaman ini merupakan tugas keahlian yang diberikan oleh LKP Grafologi Indonesia.

Redesign hero section tetap mempertahankan karakteristik atau ciri khas pada web,
headline konten asli, dan hanya merubah tampilan agar lebih simple, modern dan interaktif.
